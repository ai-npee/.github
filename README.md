# ai-npee/.github

本仓库保存 **AI-NPEE** 组织的公共配置：

| 路径 | 作用 |
|---|---|
| `profile/README.md` | 组织主页展示内容（GitHub 从 `.github` 仓库的 `profile/` 渲染组织首页） |
| `CONTRIBUTING.md` | 组织级贡献指南，所有仓库未被覆盖时继承此文件 |
| `CODE_OF_CONDUCT.md` | 组织级行为准则 |
| `SECURITY.md` | 安全漏洞报告流程 |
| `LICENSE` | MIT，覆盖组织自有代码与文档 |
| `.github/ISSUE_TEMPLATE/` | Issue 与 PR 模板（组织级默认） |

## 修改约定

- 面向读者的内容用中文，文件名与代码标识用英文。
- 组织级社区文件（`CONTRIBUTING.md`、`CODE_OF_CONDUCT.md`、`SECURITY.md`）放在**仓库根目录**；
  `profile/README.md` 是组织首页，只在 `profile/` 下。
- 修改后提交前先在本地预览 Markdown，确认相对链接指向正确路径。
