## 🚀 如何参与

### 🌟 作为学习者

1. **浏览资料** - 访问我们的各个仓库，查找你需要的资料
2. **提出建议** - 在 Issues 中提出改进建议或资料需求
3. **分享反馈** - 告诉我们资料的使用体验

### ✍️ 作为贡献者

1. **Fork 仓库** - 克隆你想贡献的资料仓库
2. **创建内容** - 编写、整理、优化资料
3. **提交 PR** - 提交你的贡献，等待审核
4. **参与讨论** - 在 Discussions 中与其他成员交流

### 🎓 加入组织

如果你想成为正式成员，参与更深入的协作：

1. **申请加入** - 在任意仓库提交 Issue 说明你的意向
2. **展示能力** - 通过提交高质量 PR 展示你的贡献
3. **获得邀请** - 管理员审核后将发送邀请

## 📜 开源协议

本组织的资料遵循 [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) 协议：

- ✅ **自由使用** - 可以自由使用、复制、分发
- ✅ **允许修改** - 可以修改和演绎
- ⚠️ **署名要求** - 必须给出适当的署名
- ⚠️ **相同方式共享** - 若修改，必须以相同协议分发

代码类项目遵循各自仓库指定的开源协议。
